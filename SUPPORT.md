# Support

MD Ops is a **single-operator, local-first** application maintained on a best-effort basis by one maintainer. There is no hosted service, SLA, or commercial support channel.

## Where to look first

- [README.md](README.md) — quick start, configuration of Markdown roots, API contract overview.
- [docs/MCP.md](docs/MCP.md) — running and configuring the MCP server for agents.
- [SECURITY.md](SECURITY.md) — security boundary, safe defaults, and private vulnerability reporting.

## Questions and bug reports

Open an issue on the project's repository. Please include what you ran, what you expected, and what happened. Do not include real vault content, credentials, absolute local paths, or exploit details — see [CONTRIBUTING.md](CONTRIBUTING.md) for the full scope rules.

Security vulnerabilities are **not** handled through public issues — follow the private reporting steps in [SECURITY.md](SECURITY.md).
