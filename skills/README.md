# MD Ops agent package

This directory contains portable instructions for agents that interact with an MD Ops service. It contains no customer data, host paths, tokens, or service URLs.

- `skills/md-ops/SKILL.md`: safe browser/API workflow.
- `skills/md-ops-mcp/SKILL.md`: MCP configuration and tool-use workflow.

Install or copy these skills into the agent system that your organization uses. Configure the service URL and any credential material outside the skill files.
