# Code of Conduct

MD Ops is a small, MIT-licensed open-source project. Contributors are expected to:

- Be constructive and respectful in discussions, issues, and code review.
- Keep contributions within the scope rules in [CONTRIBUTING.md](CONTRIBUTING.md): no personal data, credentials, real vault content, or private infrastructure details.
- Follow the security boundary documented in [SECURITY.md](SECURITY.md); never post exploit details or secrets publicly.

Unacceptable behavior includes harassment, trolling, publishing others' private information, and any conduct a reasonable maintainer would consider unprofessional.

Reports of conduct violations go to the repository maintainer privately (the same direct channels as security reports). This is a single-maintainer project; reports are handled on a best-effort basis.
